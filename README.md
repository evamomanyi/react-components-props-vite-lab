# Personal Blog Website Using React Components and Props

## Overview

This project demonstrates the use of React Components and Props by building a simple personal blog website.

The application displays:

- Blog Header
- About Section
- Dynamic Article List
- Individual Articles

## Component Tree

```text
App
├── Header
├── About
└── ArticleList
    └── Article
```

## Technologies Used

- React
- JSX
- JavaScript
- CSS
- Jest
- React Testing Library

## Installation

Clone the repository:

```bash
git clone https://github.com/evamomanyi/react-blog-lab.git
```

Navigate to the project:

```bash
cd react-blog-lab
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

## Running Tests

```bash
npm test
```

## Features

- Component-based architecture
- Props for data sharing
- Dynamic rendering using map()
- Accessible images using alt attributes
- Unit testing with Jest
